# 9PM Bar & Cafe — Premier Nightlife & DJs | Palolem, Goa

A luxury, high-conversion Single Page Application (SPA) built with **React.js** and **Tailwind CSS** for **9PM Bar & Cafe** located in Mohanbagh, Palolem, Canacona, South Goa.

---

## 🌟 Key Highlights & Features

- **Dark, Cinematic & Premium Aesthetic**: Deep Maroon Red (`#8F0000`), Dark Surface (`#1A1A1A`), Pure Dark (`#0A0A0A`), and subtle audio visualizer equalizer accents.
- **Conversion-Optimized CTAs**:
  - Direct Click-to-Call action (`tel:8287696969`).
  - Interactive Table & VIP Lounge Reservation popup with pre-filled WhatsApp messaging.
  - Interactive Google Maps direction card and location details.
- **Social Proof & Verified Ratings**:
  - Google Rating: **4.6 ★** with **1,070+ Reviews**.
  - Verified review cards with theme filters (Music & Drinks, Atmosphere, Food, Cocktails).
- **Curated Music & DJ Culture**:
  - Highlights international artist lineups across subgenres (Techno, Reggae, Dub, Reggae Fusion, Afro House, Deep Progressive).
  - Weekly sound program and event lineup schedule.
- **Gourmet Food & Craft Mixology**:
  - Full late-night kitchen operating till 4:00 AM.
  - Highlights Sushi platters, Char-grilled Kebabs, Tempura Prawns, Paneer Chilli, and midnight Dal Khichdi.
- **Visuals & Masonry Gallery**:
  - Interactive category filters (DJs, Cocktails, Nightlife, Food, Crowd, Atmosphere).
  - Lightbox modal with keyboard and touch navigation.
  - Simulated Instagram feed preview.
- **Decoupled Local Data**:
  - All content, menus, reviews, and timings are managed in `src/data/ninePM.js` for instant updates.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
Generates an optimized static production bundle in the `build/` directory ready for deployment.
